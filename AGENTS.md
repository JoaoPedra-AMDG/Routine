# Daybook

- Build the app in Flutter and Dart.
- Keep all visible text necessary and functional; do not use slogans or motivational copy.
- Use the cream, taupe, terracotta, gold and sage colours from Foc Fast with slightly more vibrant accents.
- A moved recurring task changes only the selected day unless the user explicitly edits the whole routine.
- Keep all-day events and events with unconfirmed times above the timetable.
- Store completion and skip state separately for each day.
